# 行知 Navi · 本地部署（Mac）

离线可运行的静态 Demo。不需要 Node、不需要安装依赖。

路径：看见状态 → 找到问题 → 获得建议 → 开始行动。

## 方式一：双击启动（推荐）

1. 解压 `行知Navi-mac.zip`
2. 进入文件夹 `xingzhi-navi`
3. 第一次若提示无法打开，在访达中右键 `启动.command` → 打开
4. 浏览器会访问 http://127.0.0.1:8765/

停止服务：双击 `关闭服务.command`

## 方式二：直接打开页面

双击 `index.html`，用 Safari 或 Chrome 打开即可。  
所有脚本都在本地，无构建步骤。有网络时会尝试加载 Google Fonts；无网络则使用 Mac 自带的苹方 / 宋体。

## 方式三：终端

```bash
cd xingzhi-navi
python3 -m http.server 8765
```

浏览器打开 http://127.0.0.1:8765/

## 交互

- 顶部四个领域卡片：筛选工作 / 学习 / 生活 / 项目，卡住的领域带一个小红点
- 顶部时间是实时的，会自动走
- 首屏「现在最该做的一件事」：一进来就给出当前最该动手的一件，可直接「开始做」或「去看看」
- 状态地图：单击节点看详情；再点领域或项目可下钻
- 筛选芯片：全部 / 还没做完 / 只看卡住的
- 虚线：跨节点依赖
- 详情里可以改状态：卡住了 / 正在做 / 做完了。改动会存在本地，刷新还在
- 一件事做完后，依赖它、原本「在等前面的事」的节点会自动变成「正在做」
- 「开始做」进入专注计时；结束时点「做完了」会把它标记完成并让后面的事跟着动，点「先到这儿」则只记一笔
- 做完的事会计入首屏「今天已经做完 N 件」

## 自己编辑（把它当真工具用）

- 详情底部：`＋ 新建项目 / 新建子任务`、`编辑`、`删除`
- 领域下能建项目，项目下能建子任务；删除会连同它下面的内容一起删掉
- 叶子节点可直接拖动进度条改百分比，拖到 100% 自动标记完成
- 编辑弹窗里可以改名称、下一步、提示、预计分钟、状态，以及勾选它「在等哪些事」（依赖）
- 第一次编辑某位成员时，会把当前状态固化成一份可编辑副本，之后所有改动都存本地（`localStorage`），刷新还在
- 想恢复内置的示例数据：在浏览器控制台执行 `localStorage.clear()` 后刷新
