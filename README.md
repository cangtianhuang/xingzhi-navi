# 行知 Navi

一个人的「状态操作系统」——打开只回答两个问题：**现在卡在哪 / 下一步做什么**。

零依赖静态应用，纯浏览器运行，不需要 Node、不需要构建步骤。线上地址（内网）：<https://xingzhi-navi.popo.baidu-int.com>

## 本地运行（Mac）

离线可运行。路径：看见状态 → 找到问题 → 获得建议 → 开始行动。

## 方式一：双击启动（推荐）

1. 解压 `行知Navi-mac.zip`
2. 进入文件夹 `xingzhi-navi`
3. 第一次若提示无法打开，在访达中右键 `启动.command` → 打开
4. 浏览器会访问 http://127.0.0.1:8765/

停止服务：双击 `关闭服务.command`

## 方式二：直接打开页面

双击 `index.html`，用 Safari 或 Chrome 打开即可。  
所有脚本都在本地，无构建步骤。有网络时会尝试加载 Google Fonts；无网络则使用 Mac 自带的苹方 / 宋体。

## 方式三：终端

```bash
cd xingzhi-navi
python3 -m http.server 8765
```

浏览器打开 http://127.0.0.1:8765/

## 交互

- 一个人的状态操作系统：打开先看极简欢迎页，点「进入」即到「今天」——最该做的一件（主角）＋ 卡住的 ＋ 今天能清掉的，每条可直接「开始做 / 解卡 / ✓ 做完 / 去看看」
- 想看结构全貌时点顶部「看全貌」进入状态树；树里可逐层展开、拖动改归属、增删改，再点一次「← 回到今天」返回
- 常驻「快速记」：随手写一句（在忙什么 / 卡在哪 / 做完了什么）回车即记——命中已有的事就标完成或记卡点，否则用 AI 归类到领域/项目，未配 AI 则兜底到「随手记」
- 「解卡」：卡住的事可写清卡点、拆成能动的第一步（可让 AI 帮想）再开始做
- 顶部四个领域卡片：筛选工作 / 学习 / 生活 / 项目，卡住的领域带一个小红点
- 顶部时间实时走；「搜索」（或 `Cmd/Ctrl + K`）按名称 / 现状快速跳到某件事
- 顶部「提醒」：可选开启开工提醒（页面开着时每天 9:00 用系统通知提醒看一眼）
- 筛选芯片：全部 / 还没做完 / 能今天做完 / 只看卡住的
- 详情里能看「在等什么」（我依赖谁）和「完成后将放行」（谁在等我做完）
- 状态用颜色 + 符号（! ▶ ~ … ✓）双重区分，色盲也能分辨；界面跟随系统深色 / 浅色
- 一件事做完后，原本「在等前面的事」、依赖它的那些事会自动变成「正在做」，并有「X 可以开始了」的提示；反过来，若把已完成的前置又改回未完成，被放行的下游也会退回「在等前面的事」
- 「开始做」进入专注计时；结束时点「做完了」会把它标记完成并让后面的事跟着动，点「先到这儿」则只记一笔
- 做完的事会计入首屏「今天已经做完 N 件」（只统计当天，跨天自动归零）

## 自己编辑（把它当真工具用）

- 详情底部：`＋ 新建项目 / 新建子任务`、`编辑`、`删除`
- 领域下能建项目，项目下能建子任务；删除会连同它下面的内容一起删掉
- 最末一层的「具体的事」可直接拖动进度条改百分比，拖到 100% 自动标记完成
- 编辑弹窗里可以改名称、下一步、提示、预计分钟、状态，以及勾选它「在等哪些事」
- 在状态图上按住一张卡片拖动，可以把它挪到别处：项目挪到别的领域下、子任务挪到别的项目下（连同它下面的内容一起走）。为保持「领域 › 项目 › 具体的事」三层结构，跨层级或挪进自己下面等不合法的目标会被忽略，只有合法落点才高亮。轻点不拖动仍是选中 / 进入下一层，键盘 Tab 聚焦后按 Enter / 空格同样可选中
- 第一次编辑结构时，会把当前状态固化成一份可编辑副本，之后所有改动都存本地（`localStorage`），刷新还在
- 想恢复内置示例：状态图为空时首屏会出现「恢复示例数据」按钮，点它即可（会清掉本机改动，回到「林予」示例）

## 接大模型想「下一步」（可选）

顶部「AI」按钮里配置一个 OpenAI 兼容接口（OneAPI）：

- 接口地址默认 `https://oneapi-comate.baidu-int.com/v1`，填入 API Key 和模型名（默认 `gpt-4o-mini`）即可
- 配好后，具体的事 / 项目详情里会多出「让 AI 想一步」——点一下，模型会读当前状态、卡在哪、在等什么，回一个具体的「下一步」并写回（这一步也能撤销）
- 顶部「建图」：把一段近况 / 待办粘进去（配了 AI 自动拆），或按「领域/项目/具体的事」每行手写（无需 AI），批量加到当前状态图上（可撤销），用来快速冷启动一张空图
- **安全说明**：API Key 以明文存在本机浏览器的 `localStorage`，请求只发往你自己配置的接口，不经过任何第三方。仅建议内网 / 本地使用；共用电脑记得用「清除」删掉 Key

## 会推断的「下一步」

「下一步」不再是写死的：没填的时候会按状态自动推断，标上「帮你想的」——

- 在等前面的事：提示先做完前面哪些事
- 领域 / 项目：指到里面最该先动的那件，并带上它的具体动作
- 卡住的一件事：把「卡在哪里」变成第一步
- 正在做的一件事：给一个限时的小推进

首屏「现在最该做的一件事」也用同一套规则来挑，永远指向真正能上手的一件。

## 撤销 / 重做

- 改状态、拖进度、新建 / 编辑 / 删除 / 拖动改归属、AI 写回，都可以撤销
- 顶部「↶ 撤销」/「↷ 重做」按钮，或按 `Cmd/Ctrl + Z` 撤销、`Cmd/Ctrl + Shift + Z`（或 `Cmd/Ctrl + Y`）重做
- 撤销 / 重做是本次会话内的（最多 40 步），刷新页面后清空；产生新的改动会清掉重做链
